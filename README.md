YT Downloader for ME
Deskripsi
YT Downloader for ME adalah aplikasi desktop sederhana yang dirancang untuk mengunduh video dan audio dari YouTube dengan antarmuka yang bersih dan modern. Aplikasi ini dibuat agar teman-teman saya dapat mengunduh konten favorit mereka dengan mudah tanpa harus berurusan dengan terminal atau skrip rumit.

Fitur Utama
Mode Unduh Fleksibel: Mendukung unduhan video (hingga resolusi tertinggi) dan audio (MP3).

Pemilihan Kualitas: Deteksi otomatis resolusi yang tersedia untuk video pilihanmu.

Antarmuka Ramah Pengguna: Cukup tempel tautan, cek kualitas, dan unduh.

Pembaruan Otomatis: Dilengkapi dengan fitur pengecekan pembaruan mandiri agar tetap kompatibel dengan YouTube.

Transparansi Pengembangan
Aplikasi ini dikembangkan secara mandiri dengan bantuan kecerdasan buatan (AI) untuk mempercepat proses penulisan kode dan penyusunan logika. Saya bertanggung jawab penuh atas integrasi, pengujian, dan pengembangan fungsionalitas aplikasi ini agar dapat digunakan dengan aman oleh pengguna.

Kredit & Library Pihak Ketiga
Aplikasi ini tidak akan berfungsi tanpa kerja keras komunitas pengembang hebat di balik library berikut:

1. yt-dlp: Mesin pengunduh video yang sangat andal dan terus diperbarui.

2. CustomTkinter: Library Python untuk membuat tampilan antarmuka (GUI) modern yang saya gunakan untuk aplikasi ini.

3. FFmpeg: Komponen krusial yang digunakan untuk memproses dan menggabungkan audio dan video menjadi file akhir.
